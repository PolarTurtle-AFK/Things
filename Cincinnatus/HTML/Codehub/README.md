# Codehub

A simple platform where users can upload, copy, and like programming resources.

## Built With

- React
- TypeScript
- HTML
- CSS

## How to Run

# 1. Clone the repository:

```bash
git clone https://github.com/PolarTurtle-AFK/Codehub.git
```
```bash
cd Codehub
```

# 2. Install dependencies:

```bash
npm install
```
# 3. Run
```bash
npm start
```

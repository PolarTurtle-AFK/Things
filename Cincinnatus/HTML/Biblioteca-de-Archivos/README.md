# Biblioteca de Archivos

A simple web application that allows users to view and browse stored images.

## Features

- View images
- Browse stored files

## Built With

- HTML
- CSS
- JavaScript
- TypeScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/PolarTurtle-AFK/Biblioteca-de-Archivos.git
```
2. Open the project folder:

3. cd Biblioteca-de-Archivos

4. Open index.html in your browser.

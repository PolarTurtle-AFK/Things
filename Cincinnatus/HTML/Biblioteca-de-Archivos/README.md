# Biblioteca de Archivos

A simple web application that allows users to view and browse stored images.

## Built With

- HTML
- CSS
- JavaScript
- TypeScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/PolarTurtle-AFK/Biblioteca-de-Archivos.git
```
2. Open index.html
